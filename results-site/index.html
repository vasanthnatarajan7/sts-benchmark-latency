Worth knowing before you quote a number

  • Prism was fastest on three of four clips and slowest on clip B, where almost all of its 1.5 s was turn detection.
  • Grok took ~3.5 s on recording A1 in every run, but 0.96 s on a second recording of the same sentence (A2). Turning the volume down or adding silence to A1 didn't change it. Unexplained.
  • Gemini was the steadiest: all four clips within 88 ms.
  • OpenAI's ~0.74 s turn detection is its default end-of-speech window, which is configurable. Nothing was tuned for any model.
  • With n=20, p95 is effectively the second-highest trial.

How it was measured

  • Raw WebSockets, no SDKs, one adapter per vendor: Rime Prism prism-v0, xAI grok-voice-3.0, Google gemini-3.8-live, OpenAI gpt-realtime-2.1.
  • Recordings streamed in real time (paced by the wall clock), PCM16 16 kHz mono; OpenAI's input resampled to 24 kHz as its API requires.
  • Speech end found from the recording's own audio level; time measured from when that audio was sent. Network time is included and identical in method for every model.
  • Each trial is a fresh connection; no retries; failures, early replies and talk-overs are counted (all zero here).
  • One speaker, one machine and network, one evening. Not measured: answer quality, voice quality, barge-in, phone-line audio.
  • Prism calls ran on Rime API credits. The full write-up with method and code follows midweek.
